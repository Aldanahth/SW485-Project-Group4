# University Student Retention & Advisory Dashboard

**Course:** SWE485  
**Group:** 4

## Project Overview

This project focuses on analyzing university student data to identify factors associated with academic performance, student retention, and dropout.

The project aims to examine patterns in student characteristics and academic outcomes and establish a foundation for developing a student retention and advisory dashboard.

## Dataset Description

The dataset contains 4,424 student records and 37 columns, consisting of 36 input features and one target variable.

The features include demographic, socioeconomic, and academic information. The target variable, `Target`, represents three student outcomes: Graduate, Dropout, and Enrolled.

The dataset is available in the `Dataset/data.csv` file.

## Phase 1: Data Exploration

The initial data exploration is documented in `Phase1_Data_Exploration.ipynb`.

The notebook covers:

- Examination of the dataset structure and dimensions.
- Identification of data types.
- Assessment of missing values.
- Descriptive statistical analysis.
- Analysis and visualization of the target class distribution.

The initial inspection identified no missing values in the dataset. The target classes are unevenly distributed, with 2,209 Graduate records, 1,421 Dropout records, and 794 Enrolled records.
