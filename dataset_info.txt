Original Purpose:
The dataset was created to help reduce academic dropout and failure in
higher education. It uses machine learning techniques to identify
students at risk at an early stage of their academic path, so that
support strategies can be put in place.

Dataset Description:
- Records: 4,424 students
- Features: 36 (demographic, socioeconomic, macroeconomic, and academic)
- Target variable: "Target" with 3 classes: Dropout, Enrolled, Graduate
- Task type: Multi-class classification
- Missing values: None reported by the source
- File format: CSV, semicolon-separated (;)
